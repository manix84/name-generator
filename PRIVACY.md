# 🔒 Privacy Policy

Last updated: 2026-06-11 📅

Name Generator is a static browser app for generating random two-word names.

## 🧺 Data Collection

The app does not ask for personal information, does not provide accounts, and does not intentionally store generated names on a server.

Generated names are created in your browser from word lists included with the app.

## 🍪 Cookies and Local Storage

The app does not intentionally set cookies or use local storage.

## 🌍 Third-Party Requests

The app loads fonts from Google Fonts. When those font files are requested, Google may receive standard request information such as your IP address, browser details, and the page URL.

The app is hosted on GitHub Pages, which may process standard web server logs for security and operations.

## 📝 Changes

Privacy changes will be documented in this file and, where relevant, in `WHATSNEW.md`.
