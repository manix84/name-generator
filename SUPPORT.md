# 🙋 Support

Name Generator is maintained as a small personal project.

## 🆘 Getting Help

Use GitHub Issues for:

- 🐛 Bugs in the generator.
- 🚢 Broken deployment or build behavior.
- ♿ Accessibility problems.
- ✨ Small feature requests.

Please include the browser, operating system, and steps to reproduce when reporting a bug.

## 🚧 Not Covered

This project does not provide formal support guarantees, service-level agreements, or custom hosted deployments.
