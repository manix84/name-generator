# 🌈 Code of Conduct

## ✨ Our Standard

This project should be a friendly, practical place to collaborate. Please be respectful, constructive, and clear when opening issues, reviewing pull requests, or discussing changes.

Examples of welcome behavior: 💚

- 🎯 Giving specific, actionable feedback.
- 🧘 Being patient with people who are learning the project.
- 🛠️ Focusing criticism on ideas, code, and outcomes.
- 🤝 Assuming good intent while still naming problems plainly.

Examples of unacceptable behavior: 🚫

- Harassment, insults, threats, or discriminatory language.
- Personal attacks or repeated hostile comments.
- Publishing private information without permission.
- Derailing issues or pull requests with unrelated arguments.

## 🧭 Enforcement

If you see behavior that does not meet this standard, contact the maintainer privately through GitHub. Reports will be reviewed with context and handled at the maintainer's discretion, which may include comment deletion, temporary blocks, or permanent bans from the project.

This code is intentionally short, but the expectation is real: keep the project useful and welcoming.
