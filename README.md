# Name Generator

A small React app for generating random two-word names.

## Scripts

Run the local Vite dev server:

```sh
npm start
```

The app runs at `http://127.0.0.1:3001/name-generator/`.

Run the Vitest suite:

```sh
npm test
```

Build for production:

```sh
npm run build
```

The production build is emitted to `dist/` and uses `/name-generator/` as its base path for GitHub Pages.
